constants.php

Constantes globais da aplicação SkillConnect

Centraliza todos os valores de status e perfil usados em múltiplas partes do sistema. Use estas constantes em vez de strings literais nas comparações PHP e nas chaves de arrays. Strings dentro de queries SQL devem permanecer como literais, pois o MySQL não tem acesso a constantes PHP.
